Congratulations on finishing your first game! Our Basket Catch game covered all of the fundamentals of working in the Godot engine. Now it's time for us to extend that knowledge by creating a more complete project. We will be making a short platformer (games like Mario, Sonic, Crash Bandicoot, etc.) using both the tools we previously learned about as well as some new ones!

First, let's discuss what this project will look like in the end. We will have the following scenes that the player will move between:

* Start Screen
* Level 1 Scene
* Level 2 Scene
* Lose Screen
* Win Screen

We'll also be making a few other scenes to place in the above scenes:

* Player Scene
* UI Scene
* 2 Enemy Scene
* Enemy Spawner Scene
* Collectible Scene
* Out of bounds Scene
* Moving Platform Scene
* Goal Scene

# Let's get started!

Create a new project, name it "lastname-platformer", then do the following:

1. Make empty scenes for the following: (These scenes will have Node2Ds as roots. Make sure to rename them!):
	* Start
	* Level 1
	* Level 2
	* Lose
	* Win
2. Make a scene with the correct root nodes for:
	* Player
	* UI
	* Collectible
3. Make a global with the following properties:
	* Lives
	* Score
4. Makes folders for each scene. Your file system should have the following folders:
	* Start
	* Level 1
	* Level 2
	* Lose
	* Win
	* Player
	* UI
	* Collectible
	* Enemy 1
	* Enemy 2
5. Put the scene files in their correct folder. 
6. Download this asset pack and place the assets in the appropriate folders in your project.
	* [Asset Pack](https://drive.google.com/file/d/1rpI8gOl87ci8IJywkIO_sYiu7HuJUG2C/view?usp=sharing)
